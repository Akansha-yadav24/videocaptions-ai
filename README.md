**Transcribe Hindi & English videos → Translate to English → Generate styled captions automatically.**

VideoCaptions AI is a lightweight AI tool that converts videos into **fully captioned videos** using **OpenAI Whisper**.  
It supports **automatic transcription, translation, styling, and subtitle export** with both a **web UI and CLI interface**.

---

# ✨ Features

- 🎙 **Speech-to-Text** using OpenAI Whisper
- 🌐 **Hindi & English Auto Detection**
- 📝 **Automatic Translation to English**
- 🎨 **Multiple Caption Styles**
- 📍 **Caption Position Control** (Top / Middle / Bottom)
- ⌨️ **Typewriter Animation**
- 📄 **SRT Subtitle Export**
- 🖥 **Streamlit Web Interface**
- 💻 **Command Line Interface**
- 🐳 **Docker Deployment Ready**
